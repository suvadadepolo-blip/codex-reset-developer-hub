Quickstart

curl
curl -sS https://codex-reset.com/api/forecast \
  -A 'myproject/1.0 (+https://myproject.example)' \
  | jq '{p24: .probabilities.rounded_24h,
         p48: .probabilities.rounded_48h,
         last: .last_reset_at}'

Server-side readers: send a User-Agent that names your project and gives a contact URL. Poll at most once a minute and honor Retry-After on a 429.

One condition

Show the source

If your site, app, bot, dashboard, API or MCP server shows this data to other people, name and link the source on the same surface.

Data: codex-reset.com

Private scripts do not need visible credit, but server-side readers still need an identifying User-Agent.

Boundaries

Use the data honestly

  • The forecast is experimental. It is not an OpenAI schedule, leak, promise or commitment.
  • A rising forecast is not a reset. Use the dated timeline to determine whether a reset was announced.
  • Depend only on documented fields. Other response fields may change or disappear.
  • The service cannot see your OpenAI account, quota or personal usage.
